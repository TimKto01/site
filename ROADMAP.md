# План разработки

0. Техническая основа: Next.js, TypeScript, Tailwind, shadcn/ui, Prisma, PostgreSQL, проверки и документация.
1. Демонстрационная витрина: главная, каталог 12–20 товаров, поиск, фильтры, карточка, корзина, адаптивность и тесты.
2. База данных и администрирование: модель, миграции, авторизация, CRUD, загрузка изображений, настройки.
3. Заказы: серверная валидация цен и остатков, резервы, идемпотентность, гостевое оформление, ручное подтверждение.
4. Telegram: отдельный процесс grammY, права по ID, общий сервис заказов, outbox.
5. Оплата: ЮKassa sandbox, верификация через API, идемпотентность, фискализация.
6. Доставка: адаптеры СДЭК и Почты России, тарифы и отправления, ручной режим при отсутствии доступа.
7. Качество: аналитика, SEO, безопасность, производительность, резервное копирование.
8. VPS и публичный запуск: HTTPS, процессы, восстановление, DEPLOYMENT.md и запусковой чек-лист.

Переходить дальше только после проверки критических критериев текущего этапа. Реальные платежи и отправления — только с отдельным разрешением владельца.
